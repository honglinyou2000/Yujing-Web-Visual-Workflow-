# Yujing Web Visual Workflow

A five-stage skill for building **high-aesthetic, tech-feel, strongly interactive** company websites and landing pages — without the generic AI-template look, and without inventing company facts.

## What it does

1. **Direction** — lock mood, type, color, and one signature motion  
2. **Design system** — freeze reusable tokens and motion rules  
3. **Strong-interaction build** — scroll story, magnetic CTAs, card motion, parallax (Strong / Standard / Reduced)  
4. **De-slop** — remove cheap gradients, nested cards, muddy hierarchy  
5. **Polish** — desktop + mobile audit (contrast, tap targets, meaningful motion)

## How to use

In Cursor / Codex-style agents: open the skill under `.cursor/skills/yujing-web-visual-workflow/`, then run stages **in order** — do not load all four reference skills at once.

## Boundaries

- No fabricated company copy, licenses, case metrics, or unapproved product claims  
- Prefer “diagnose first, then solution” IA over thick product-catalog pages  
- Honor `prefers-reduced-motion`
